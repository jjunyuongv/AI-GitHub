관리자

🧪 실험실

모델·effort·시스템 프롬프트를 바꿔가며 요약을 실행한다.

📊 실행 기록

실험실과 프론트(/analyze)의 모든 호출을 시간·토큰·비용과 함께 조회한다.

💳 사용량

실행 기록에서 집계한 호출 횟수·토큰·비용(추정)과 GitHub API 잔여 요청 수.

🔍 검색 품질

임베딩 모델별 코드 검색 정확도를 평가셋으로 재고 나란히 비교한다. 한국어 질의가 핵심 지표다.

🗂️ 스냅샷

저장소별 색인 상태와 그 청크를 만든 청킹 규칙. 규칙이 바뀌어 낡은 색인을 여기서 찾는다.
