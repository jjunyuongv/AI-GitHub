## 수정 D — 접미사를 경계로 맞춘다 (2026-08-28)

브랜치 `fix/suffix-boundary`. **무과금으로 끝냈다.** 위 조사에서 곁가지로 나온 것이다.

### 답변의 잘못이 아니었다

`_matching_paths` 가 `p.endswith(name)` 였다. 그래서
`".../ApnsPayload.java".endswith("Payload.java")` 가 참이고, 답변이 `Payload.java` 라고
**정확히 적어도** 둘이 맞아 "접미사 중복"으로 버려졌다. 접두어가 붙은 동명 클래스가
흔한 Java 저장소에서 실측됐고(`I`+인터페이스명 관례도 같은 모양이다), 남은 7건이 전부
이 형태였다.

```python
return [p for p in paths if p == name or p.endswith("/" + name)]
```

**줄여 쓴 경로는 그대로 받는다** — 줄임은 언제나 경계에서 시작한다
(`jpa/UserService.java`). 걸러지는 것은 파일 이름 **중간에서 잘린** 문자열뿐이고,
그건 애초에 다른 파일이다.
